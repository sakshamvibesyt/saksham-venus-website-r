SAKSHAM VENUS — WEBSITE

FILES
- index.html: complete responsive website
- profile.jpg: add your own profile photo here (optional)

HOW TO ADD YOUR PHOTO
1. Choose a clear photo of yourself.
2. Rename the file exactly to: profile.jpg
3. Put it in the same folder as index.html.
4. If you don't add a photo, the website shows the initials "SV".

PUBLISH FREE WITH GITHUB PAGES
1. Sign in at https://github.com/
2. Create a new public repository named exactly: sakshamvibesyt.github.io
   (If that username isn't yours or GitHub says it's unavailable, create another repo and use its repository Pages settings instead.)
3. Upload index.html and, optionally, profile.jpg to the repository's root.
4. Open the repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for the Pages deployment to finish. Your website URL should be:
   https://sakshamvibesyt.github.io/
   This URL is only correct if your GitHub username is sakshamvibesyt and the repository name is sakshamvibesyt.github.io.
8. Open the URL on your phone to test it.

GOOGLE SEARCH
1. After publishing, open https://search.google.com/search-console/
2. Add your website property. For a GitHub Pages URL, use URL prefix if that option fits your site.
3. Follow Google's verification instructions.
4. Use URL Inspection to test the homepage and click Request indexing if offered.
Google indexing is free but not guaranteed and can take time.

BEFORE PUBLISHING
- Check the social links and project descriptions.
- Only use a photo and details you are comfortable sharing publicly.
- Do not add private phone numbers, home address, passwords, API keys or bot tokens.
